# Adipose Tissue Model

MATLAB implementation of a physiology-based mathematical model of postprandial adipose tissue metabolism.

The model and experimental data are described in:

O'Donovan, S.D., Luscombe-Marsh, N.D., Eston, R.G., Petersen, A.M., Lapthorne, S., Stroeve, J.H., van Klinken, J.B., Verschuren, L., Schrauwen-Hinderling, V.B., Schrauwen, P. and Kiens, B., 2019. A computational model of postprandial adipose tissue lipid metabolism derived using human arteriovenous stable isotope tracer data. *PLOS Computational Biology*, 15(10), p.e1007400.

See model_description.pdf for further detail.
